# 复制即用的调用示例

这些是给作者使用的请求示例，按实际资料替换括号内容。没有补充资料也可以先生成受限稿。

## 写公众号

```text
使用 $chinese-public-content。
主题：[主题]
读者：[目标读者及其问题]
素材：[笔记、原稿、链接或附件]
帮我写完整公众号稿，约 2000 字。关键外部事实先核验，最多给 3 个标题。
保留我的真实立场，不编造亲历。正文之后简短列出核验限制。
```

## 改稿与去 AI 味

```text
使用 $chinese-public-content 修改下面的稿件。
保持原意、数字、事实边界和作者身份，修逻辑、重复、套话与生硬表达。
直接给完整改稿，随后列出影响原意的重要修改。
原稿：[正文]
```

## 学习个人风格

```text
使用 $chinese-public-content 学习这些作者原文的表达风格。
请区分稳定偏好、体裁差异和暂时假设，每条规则附样稿依据与反例。
本次只给风格卡，不保存全局记忆，也不把你的试写当作我的原文。
样稿及作者认可状态：[材料]
```

## 保存项目风格档案

```text
使用 $chinese-public-content。
根据我已确认的规则，将风格档案保存到 [项目中的具体路径]。
后续这个项目内可按我的明确反馈维护该档案；推断规则与确认规则分开记录。
资料：[样稿、修改意见、已确认规则]
```

## 同题公众号与微博

```text
使用 $chinese-public-content，把以下资料写成一篇公众号稿和两条可独立阅读的微博。
共用证据底稿。短版本保留改变结论的条件，编辑附件说明删改了什么。
材料：[资料]
```

## 独立审稿

```text
使用 $chinese-public-content 审核这篇稿。
本次先给审计报告，不重写。优先查主结论是否成立、来源是否支持、
有力反证、标题是否夸大以及作者亲历是否真实。未检查项如实标记。
稿件与来源：[材料]
```

## 可选行知模式

```text
使用 $chinese-public-content，启用行知模式。
主题：[主题]
当前产品资料与可公开材料：[材料]
写给：[读者]
把已有事实、试验、计划和理念分开；配置中的候选偏好可作为表达起点，
不能当作产品效果证据。没有证据的用户数、收益和提效结果不要写。
```

## 小红书文字交接

```text
使用 $chinese-public-content，把这篇稿改为小红书文字包。
给标题、正文和必要的卡片文本/封面简报，不编造亲测，保留核心条件。
只交文字，不上传账号。原稿与资料：[材料]
```

## 60 秒口播交接

```text
使用 $chinese-public-content，将这篇稿改成目标约 60 秒的口播文字包。
如环境有 video-best-practices，先用它路由。
给口语稿、分段时长估计、画面简报和证据交接；没有试读则明确时长只是估计。
只交脚本，不把它标成成片。材料：[资料]
```

## 真实反馈学习

```text
使用 $chinese-public-content 分析这次真实反馈。
分开作者声音、编辑质量和传播数据；写出替代解释与下一次验证。
本次不自动更新风格档案。数据窗口、口径与稿件版本：[材料]
```
