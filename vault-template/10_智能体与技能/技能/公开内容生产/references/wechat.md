# 公众号

## 文字包

根据用户需求交标题、导语或摘要、正文、必要来源以及可选互动。未指定数量时最多 3 个标题候选。没有要求封面或排版时，文字稿即可完成，不强行扩大制作范围。

手机阅读要点：

- 段落承载一个清楚的信息单元；长论证可以分段，不机械规定每段只能几行。
- 小标题帮助读者定位问题。不是每篇都需要小标题。
- 粗体用于少量关键结论或步骤；不要整段加粗、连续引用块和表情装饰。
- 复杂表格改成分项比较或简洁表格，避免宽表导致阅读困难。
- 保留正文中的关键来源关系。公众号链接的实际可用方式须按当前编辑器和账号预览核验；本地 Markdown 不代表外链一定可点。

## 排版模式

1. 默认 Markdown，便于编辑和迁移。
2. 用户要求富文本时，优先适配已有主题与排版工具；可生成语义清楚的简单 HTML，使用保守的行内样式，避免脚本、复杂定位及依赖外部 CSS。
3. 保持标题、段落、引用、列表和来源层次。图片预留 alt 与版权/来源说明。
4. 已有公众号工具时，查看当前能力和版本，进行手机预览后再声明通过。无法访问后台时，只标记“本地排版，平台预览未验证”。

本包没有内置 Markdown 转 HTML 引擎或秀米/公众号后台自动操作器；宿主可提供这些能力，但应单独核验。

## 封面与配图交接

文字简报可包含：核心信息、视觉概念、标题文字、品牌资源、构图重点、图片权利状态、实际账号尺寸要求是否已核验。未核验时不写死封面比例和像素值。

真实数据图必须能回溯数据；产品界面截图标明版本，概念图不能当实机效果；假设图要标注。没有可公开的真实案例时，不生成看似真实的客户证言。

生成/选图完成后还需检查：与正文事实一致、文字正确、手机可读、无隐私泄漏、版权来源可用。仅写了提示词不能说“配图完成”。

## 外部动作

沿用入口文件的授权和状态规则。动作依次区别：本地稿、后台草稿、预览、公开发布/群发。用户授权存草稿不授权公开发布。当前会话明确授权的动作继续执行，不让用户重复批准。

若没有实际发布工具，交稿与操作清单，不索取密钥后把它存进文章、配置模板或压缩包。操作出错应根据实际结果确认是否已产生副作用，避免重复上传或重复发布。
