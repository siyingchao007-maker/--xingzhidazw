# 质量审计

完整稿交付前使用；局部修改只检查相应风险。审稿先看内容成立与否，再看写得是否顺畅。以下为编辑标准，不是自动分数检测器。

## 阻断项

| 编号 | 核查 | 发现后的处理 |
| --- | --- | --- |
| Q01 | 关键事实、数字、出处或精确引语虚构/错引 | 更正、删除或降为明确未知；回查衍生稿 |
| Q02 | 主结论没有对应证据，或相关被写成因果 | 收窄结论、补足可用证据或改为假设 |
| Q03 | 自述、案例、路线图被写成总体或已实现效果 | 恢复身份、样本和状态边界 |
| Q04 | 标题/导语承诺超过正文，短稿删了关键条件 | 对齐主张，必要时改标题或格式 |
| Q05 | 作者身份、亲历、对话、成绩被添加 | 回到真实素材，假设明确标注 |
| Q06 | 未授权隐私、商业秘密或素材权利问题 | 脱敏、更换素材或等待必要许可 |
| Q07 | 上传、预览、发布等状态不符合实际结果 | 修正状态，不能靠文案完成标记 |

未解决的阻断项使整篇或受影响部分不能标为“可供作者审核”的完整合格稿。交付状态为“受限草稿”，指出具体主张/位置和所缺证据。不要把限制只埋在长篇附录里。

## 编辑项

| 编号 | 维度 | 检查问题 |
| --- | --- | --- |
| Q08 | 读者与用途 | 是否回答真实问题，还是只陈列概念？ |
| Q09 | 论证与反证 | 依据是否相关，最强合理反方是否改变结论？ |
| Q10 | 结构与密度 | 段落是否推进，有无重复、离题和空泛总结？ |
| Q11 | 作者声音 | 身份、视角、语气是否有样稿或明确要求支持？ |
| Q12 | 自然表达 | 套话、机械句式是否妨碍真实意思？ |
| Q13 | 平台适配 | 本平台版本能否独立理解，阅读负担是否合理？ |
| Q14 | 来源可用性 | 读者能否检查关键外部主张，是否误泄露私人资料？ |
| Q15 | 品牌与承诺 | 是否与已确认配置相符，候选表达是否冒充事实？ |
| Q16 | CTA 与资产 | 动作、入口、图片和图表是否真实且属于需求？ |

## 执行与修订

1. 在不受用户态度影响的前提下重读标题和正文，寻找最容易被误解和最难证明的主张。
2. 用证据账本实际核对主要事实；不要仅凭熟悉感勾选通过。
3. 检查主要反证、适用范围及作者自述边界。
4. 标记具体位置、问题、影响和修复方案。仅在本次任务已授权改稿时直接修订；只审不改时给出修复方案，不擅自重写。
5. 对修订内容复查；事实更正时检查所有衍生版本，语气调整时检查命题是否变强。

使用 [审计报告](../assets/templates/review-report.md)。没有独立审稿人时标为“执行者自查”。需要独立审查且宿主允许时可使用独立代理，但不能仅因写作任务存在就无限扩张审稿流程。

## 结论格式

- **可供作者审核**：阻断项已处理，编辑质量满足当前用途；不等于保证事实永远正确、平台一定通过或传播有效。
- **修订后再审**：有可修复问题，尚需完成修改与复查。
- **受限草稿**：关键资料/许可/核验能力不足；明确受影响部分和下一步。

置信度只针对有意义的命题，并说明依据强弱。不得将来源等级、字数达标和套话数量加权成“可信度 93%”。未检查项写“未检查”，不能写“通过”。
