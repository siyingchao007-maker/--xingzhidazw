# 每日记忆与灵感采集 v2.0

## 来源

基于现有：

```text
10_智能体与技能/自动任务/每日记忆与灵感采集.md
status: draft
```

源文件明确“每日”，但没有提供具体执行时间。

因此本 Automation：

```text
cadence = daily
time = null
status = draft
```

不能凭空指定“每天 21:00”等时刻。

---

# 目的

低摩擦收集当天零散：

- 经历；
- 灵感；
- 思考；
- 感受；
- 决定；
- 行动；
- 人物信息；
- 项目信息；
- 外部资料。

首要任务：

```text
先准确捕获
再谨慎整理
```

---

# 输入规则

用户可能只输入：

- 一句话；
- 几个关键词；
- 语音转文字；
- 一个不完整想法。

不要求用户先整理好。

---

# 处理

1. 保留原始表达与关键措辞。
2. 分类。
3. 提取明确出现的时间、人物、项目、地点、背景。
4. 不补造缺失信息。
5. 给 2–5 个检索关键词。
6. 可能影响长期自我理解时，只标记候选，不直接写稳定人格。
7. 灵感先保存为种子，不自动扩成长文。
8. 行动识别下一步以及未来反馈需求。
9. 普通记录不追问；缺失信息会显著影响未来理解时最多问一个简短问题。

---

# 建议路由

保留源文件：

```text
临时原始内容 → 12_资料库/00_Inbox
明确当前自我 → 01_当前的我 候选
重要经历 → 02_我的历史
项目相关 → 05_目标与项目
重要判断 → 06_判断与决策
下一步验证 → 07_行动
结果 → 08_结果与反馈
有出处事实 → 11_证据与来源
跨时间验证的稳定认识 → 才考虑 09_认知资产
```

---

# 运行方式

不新增第 18 个 Skill。

Automation 触发后把采集任务交给：

```text
xingzhi-agent-orchestrator
```

总控根据内容选择现有 Skill。

若只是捕获一条原始信息，可以直接形成结构化 capture request，不要求跑复杂 Skill。
