# 智能体与技能总览

Agent 负责选择工作方式，Skill 负责执行具体方法。默认由行知总控接收请求，每轮通常只选一个主要 Skill；辅助 Skill 和认知透镜按必要性加入。

## Agent

- [[智能体/行知总控/智能体说明|行知总控智能体]]：默认入口与任务编排；
- [[智能体/知识整理/智能体说明|知识整理智能体]]：来源、冲突、结构与知识候选；
- [[智能体/判断校准/智能体说明|判断校准智能体]]：证据、反证、失败条件与关键未知；
- [[智能体/行动教练/智能体说明|行动教练智能体]]：最小行动、完成标准、结果与复盘；
- [[智能体/用户连续性与成长/智能体说明|用户连续性与成长分析智能体]]：交互事件、偏好候选和成长路径；
- [[智能体/对话整理工作流/智能体说明|对话整理工作流智能体]]：可见回答后的内部合并整理。

## Skill

查看 [[技能/技能-索引|技能索引]]。Skill 正文是 `SKILL.md`，配置文件用于发现和路由，注册表用于索引。六个认知透镜通过 `00_系统/能力运行时` 的活动版本运行。

## 权限边界

Agent 与 Skill 不授予新的文件、外发、命令、删除或知识写入权限。任何能力即使被显式调用，也必须接受当前读取范围、本地校验、审核和可撤销规则。
