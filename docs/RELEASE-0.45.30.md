# 行知 0.45.30

本版本修复 Windows 目录联接下的冷日志启动误报。

- 允许插件库位于用户明确配置的父级目录联接之下，例如 `Documents\\Codex` 指向另一块磁盘。
- 安全检查从冷日志根目录开始，只判断插件实际控制的根目录及其内部目录。
- 冷日志根目录或内部目录如果自身是符号链接、目录联接或非目录路径，仍会被拒绝。
- 不迁移、不重签、不清空现有冷日志；原有事务签名与本地密钥保持不变。
- 增加真实文件系统回归测试，同时验证合法父级联接和内部路径逃逸两个方向。

## 验证范围

- 正式日志只读健康检查通过：无待处理意图。
- 临时副本完整解包通过，事务代次、知识事务和索引事务均可读取。
- 发布时继续同步桌面双授权签发中心；协议、签发 Key ID 与能力包不匹配时停止发布。
