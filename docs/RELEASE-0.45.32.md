# 行知 0.45.32

仅处理设计对照审计的 A01、A02，不改变五模块结构、联网策略、标签、界面或 Skill 正文。

## A01：让画像更新尊重整理权限

- “整理前确认”仍按既有语义保存原始交互，但不单独启动用户连续性分析、不自动更新当前画像、画像修订、成长事件和成长路径。
- 用现有“仅记录交互”状态说明原因；不把没有完整候选的计数冒充可审批的画像队列。本次不增加画像审批界面。
- 普通知识候选仍使用原有确认卡；共享对话整理仍可能分析相关内容，本次没有关闭它。
- 后台任务每次检查自己所属会话的权限，不误用当前活动会话的权限。
- 在分析返回后、服务读取和规划完成后再次检查授权。改为确认、只读、仅记录，或对话已归档/删除时，不开始新的画像/成长提交。
- 交互账本异步读取后也重新检查是否仍允许记录，避免切为只读后启动新的账本提交。
- 已经开始的事务继续使用原来的完成/补偿语义；不声称可以瞬时取消已经发出的磁盘 I/O。

## A02：重载保留“仅记录”

恢复状态保留合法的 automatic / record-only 选择；只有缺失或非法值才使用 automatic 默认。不迁移、删除或重写历史知识。

## 交付范围

仅公开程序与版本文件需要安装；data.json、冷日志、本地日志密钥、能力包、账号凭据、原始对话和正式知识不覆盖。发布时按既有流程同步桌面授权中心版本说明及校验结果，不改签发密钥和签发记录。
