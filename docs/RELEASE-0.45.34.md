# 0.45.34：隐藏能力管理入口

日期：2026-10-23。

按用户要求，移除对话能力配置栏的管理图标和调律页「和弦」中的「能力管理」入口；空目录提示不再引导进入管理窗口。

## 保留的日常能力

- Skill 与透镜选择器、Agent 选择、自动/手动等既有调用模式。
- 选择器中的固定候选、固定调用、下一轮、禁用及保存行为。
- 选择待启用扩展时的正常启用、依赖校验、失败提示和保存流程。
- 能力目录扫描、正文读取、路由、授权检查、已有扩展及其启用设置。

只移除界面入口，内部管理模块保留用于维护；没有删除 Skill 定义、修改治理规则或扩大权限。管理窗口原有的空值渲染问题不属于本次修复，普通界面不再提供进入该窗口的入口。高级发布、回退、全局停用和模拟功能也随入口隐藏；对话选择器中的「禁用」仍是既有会话选择行为，不等同于全局停用扩展。

## 版本与安装边界

本次包含程序界面变更，插件版本提高到 0.45.34。使用独立 build/check/test 命令，不运行 release:local。桌面授权中心和能力包不属于本次入口隐藏变更。

安装时只替换已校验的公开程序文件，并保留原程序备份；不覆盖私人状态、历史、日志、密钥、授权码或 Skill 文件。需要回退时，退出 Obsidian 后恢复同一备份中的程序文件即可。

## 验证

- 全套离线回归 175/175 通过，包括选择器保存、选中后启用、失败处理、能力读取和路由相关用例。
- 构建包含 174 个模块；222 个文件语法检查、408 个相对依赖检查和源码/产物一致性检查通过。
- 独立 Obsidian 1.14.4 测试库使用合成空会话，验证初次启动、保存后重载和调律页面正常。
- 实际 DOM 中两个管理入口均不存在；Skill / 透镜选择器可正常打开、取消；Agent 模式控件保留。未改变选择或调用模式。
- 独立宿主未记录控制台错误、警告或异常；无外部请求、账号登录或模型调用。
- 真实模型调用质量不在本次验证范围内；没有修改调用路径或能力正文。
