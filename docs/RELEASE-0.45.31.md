# 行知 0.45.31

修复大型冷日志恢复阻塞 Obsidian 插件载入的问题。

- 在插件载入时立即注册原有四种视图，显示“正在恢复行知”。
- 将完整恢复保存在可跟踪的后台任务中，Obsidian 可以继续载入和打开其他页面。
- 全部恢复、原签名校验和运行时初始化完成后，自动打开原页面并保留页面状态。
- 恢复期间暂停保存；发生错误时保留原数据并提供启动诊断。
- 关闭或禁用插件时取消后续初始化，避免异步任务在退出后重新创建运行时或打开页面。
- Judgment Kernel 扩展等待恢复任务完成后安装，不延长插件载入阶段。
- 已正常运行的会话仍允许在卸载时保存中断回答，保持正文保留机制。

## 证据与边界

正式日志健康，含 1,702 条知识事务和 135 条索引事务，完整展开约 126 MiB。修复前曾测得 24.5 秒的首次磁盘恢复，热缓存下独立 Obsidian 全初始化约 3.6 秒。

试验性提升读取并发未显示稳定改善，未纳入发布。发布仍使用原来的 16 路受控读取，并保持全部事务、正文、签名、意图检查与路径安全检查。
