## 安装与启用

只把 `vault-template/10_智能体与技能/技能/多元视角/` 中的两个文件，按同构路径放到目标 Vault 的 `10_智能体与技能/技能/多元视角/`。

现有目录扫描器能发现该扩展，无需修改受保护注册表。首次发现默认未启用，配置中的 `enabled` 不能代替用户实际启用状态。

正常界面入口：能力管理 → 重新扫描 → Skill → 多元视角 3.1.0 → 预览并启用 → 确认启用。启用应走插件的 `setCapabilityEnabled` 正常持久化入口，不手改 `data.json`。

此处技术类型为 `task`，是为了使用现有未注册扩展兼容通路；在界面归入 Skill，不冒充已经注册为正式认知透镜。`controlsFinalLayout:false` 保留本轮主要 Skill 和用户指定格式的优先权。

## 权限与运行边界

- `readScopes:[]`、`toolRequests:[]`、无必需依赖；不因为正文写了“必须联网”而新增权限、扩大读取或自动调用其他 Skill。
- 联网服从当前对话的网络许可和引擎可用能力。当前外部 API 搜索工具的单轮预算仍为 2 次；本次不把它提升为正文建议的 4–8 次，因此不能保证所有引擎都逐项兑现检索次数。
- 没有联网能力时，正文要求明确告知未核实；不能把历史或模型记忆冒充刚检索的资料。
- 原有被动建议、手动或自动模式保持原样。安装和启用不等于每轮必定推荐、提交、确认读取或完成；这些状态仍应分开记录。
- 不进行真实模型调用来证明方法效果。机器验证只证明发现、权限门、明确选择和完整读取等可观察环节，不证明模型遵循了方法。
