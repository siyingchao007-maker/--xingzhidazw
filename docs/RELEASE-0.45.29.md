# 行知 0.45.29

本版本修复被动建议模式下，模型已经申请主 Skill、但长上下文预算复核将其误记为 `NOT_ELIGIBLE` 的问题。

- 在 Codex 首轮请求发送前，为一个完整主 Skill 正文及工具结果预留空间。
- 仅压缩可再次检索的知识摘录；不删改当前用户问题、系统边界、来源路径、标题或治理元数据。
- 无法安全腾出空间时继续拒绝正文读取，不猜测或伪造模型容量。
- 将预算不足与候选失效区分为独立原因码。
- 工作面板持久记录模型是否申请、申请哪个 Skill、是否读取成功及拒绝原因，不再把申请失败统一显示为“本轮未选择”。

安全边界保持不变：每轮最多读取一个主 Skill；禁用、权限、版本、哈希、依赖与 24 KiB 正文上限仍在实际读取前复核。认知透镜的自动按需调用不在本版本范围内。
