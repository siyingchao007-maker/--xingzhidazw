# 0.45.28：长回答不中途按时限停止，中断后保留正文

日期：2026-10-19。

## 问题与修改

正常对话即使持续输出，原先仍会在启动约 15 分钟后被插件计时器中断。失败界面仅允许带特定外部 API 未完成元数据的正文继续显示；Codex 已接收并保存的内容被替换为错误摘要并隐藏。

- `src/workbench-runtime.cjs`：普通对话清除旧计时器后不再注册截止计时器。内部后台整理仍有原先的超时控制，不改变用户主动停止、真实错误和服务端完成事件。
- `src/workbench-view.cjs`：正文显示不依赖某个提供商的完成元数据。失败、取消、停止时，保留真实正文的 Markdown、复制入口和用量；错误信息单独展示，不将整篇报告染成错误卡片。没有正文时仍只显示错误，已删除消息不自动恢复。
- `src/release-file-contract.cjs` 和发布清单：升级到 0.45.28。
- `tests/interrupted-answer.test.cjs`、`tests/runtime-loader.cjs`：实际运行视图方法和计时器方法的离线回归，禁止真实外部操作。
- `scripts/check.cjs`：新发布校验产物与当前源码一致，并保留原 0.45.27 安装哈希；同版本仍强制原哈希，不把新版本伪称为原版逐字节等同。

## 验证与边界

114 项离线测试通过，构建、语法和模块引用检查通过。独立 Obsidian 宿主使用合成内容验证正文、表格、错误说明、复制入口、重载保留及 Token 显示。复制按钮启用得到验证，未读取系统剪贴板。测试库缺少治理目录的预期告警单列记录。

正式会话数据无需迁移；历史失败消息中已保存的正文会使用新显示逻辑。没有保存下来的服务器端内容无法凭空恢复；模型或网络故障仍可能中断。重试属于新请求，不宣称自动续传、免计费或返还已产生用量。

本版不改 Skill 正文、调用资格、透镜策略、知识库授权、账号凭据或自动沉淀规则。相关调度问题另行验证，不通过强制每轮加载方法掩盖。
