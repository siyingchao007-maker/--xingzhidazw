# 行知 Xingzhi · Obsidian 桌面插件

行知将个人知识、历史上下文、Skill、Agent 与判断、行动和反馈连接起来。本仓库用于私有版本管理和后续开发，不是个人知识库备份，也不构成开源授权。

## 当前版本与来源

- 当前插件版本：`0.45.27`，要求桌面版 Obsidian `1.11.4` 或以上。
- 本工程由当前已安装版本整理而来：拆分打包文件中的全部模块，保留运行包装、独立配套模块、样式、图片与获准能力定义。
- 这是**可编辑、可重建的运行版本源码快照**，不是声称已经找回全部原始开发历史。旧开发目录和历次补丁的原始提交没有上传。
- 原有运行逻辑不作升级。API 服务、账号登录、商业授权、模型可用性仍须在使用环境中单独配置和验证。

## 本地开发

准备 Node.js 22 或以上。本次整理工程的工具脚本只使用 Node.js 内置模块，没有新增第三方构建依赖。

```sh
npm run build
npm run check
npm test
npm run scan
```

`build` 将 `src/` 中的模块按 `bundler/layout.json` 顺序打包，并复制配套模块、样式与图片到 `dist/`。`check` 校验语法、相对模块依赖以及初始快照与已安装版本的逐字节一致性。开始开发并改变代码后，应明确更新发布版本及基线，不能删除校验来假装仍与旧版本一致。

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/` | 从当前运行包拆分的完整内部模块 |
| `companion/` | 插件独立加载的运行模块 |
| `assets/` | CSS、品牌与山水图片，不含聊天截图 |
| `bundler/` | 原有加载包装、模块顺序与分隔符 |
| `vault-template/` | 能力定义、注册表、治理规则、空白模板与系统契约 |
| `tests/` | 迁入的离线回归用例；不访问正式知识库、不请求真实模型 |
| `scripts/` | 构建、检查与上传前扫描 |
| `docs/` | 来源清单、验证边界及安装说明 |

## 安装与现有数据

先构建。在**独立测试库**的 `.obsidian/plugins/xingzhi-workbench/` 中放入 `dist/` 的文件；按需将 `vault-template/` 内容合并到测试库。安装到已有知识库时，先正常退出 Obsidian 并备份；不要直接覆盖已有能力定义或用户配置。

本仓库不带 `data.json`、登录令牌、模型密钥、实际授权文件、聊天历史或个人记忆。请在插件内配置自己的账号和模型。仓库可构建不等于已经完成真实模型、商业授权或所有页面的验收。

## 后续更新

先在本工程修改、构建和测试，再检查待提交文件并提交到 GitHub。GitHub 仓库不是自动同步盘，不应上传整个正在使用的个人 Vault。详见 `docs/PACKAGING.md` 和 `docs/VALIDATION.md`。
